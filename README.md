# Smart Opened Files

一个 VS Code 侧边栏插件，展示当前已打开的文件列表，并支持自定义分组管理。

## 功能

- **自动跟踪**：打开任意文件时自动加入"未分组"列表
- **分组管理**：创建、重命名、删除分组
- **文件管理**：将文件移动到任意分组；从分组移回未分组
- **关闭保留**：关闭编辑器标签后文件仍保留在列表中（显示为 closed），点击可重新打开
- **单文件单归属**：每个文件只能属于一个分组
- **工作区隔离**：分组状态按工作区持久化，切换工作区互不影响

## 使用方法

### 侧边栏

1. 点击 Activity Bar 中的 **Opened Files** 图标打开侧边栏
2. 侧边栏默认展示"未分组"容器和所有已创建的分组
3. 文件图标：
   - `$(file)` — 当前已打开
   - `$(circle-outline)` — 已关闭但仍被跟踪

### 分组操作（标题栏按钮 / 右键菜单）

| 操作 | 入口 |
|------|------|
| 新建分组 | 标题栏 `+` 按钮 |
| 重命名分组 | 右键分组项 > Rename Group |
| 删除分组 | 右键分组项 > Delete Group（文件回流未分组）|
| 刷新列表 | 标题栏刷新按钮 |

### 文件操作（右键文件项）

| 操作 | 说明 |
|------|------|
| Move File To Group | 将文件移动到指定分组 |
| Remove From Group | 将文件移回未分组 |
| Open File | 在编辑器中打开文件 |
| Close File | 关闭编辑器标签页（文件保留在列表中）|

## 开发调试

```bash

# 然后按 F5 启动 Extension Development Host
```

监视模式（实时编译）：

```bash
npm run watch
```

## 已知限制

- 第一版不支持拖拽移动文件（计划 v2 实现）
- Untitled 文件保存后，URI 变化，分组映射需手动刷新（点击刷新按钮同步）
- 不支持跨设备同步分组配置
